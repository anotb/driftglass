# Judgment surface

The Judgment surface brings prepared questions, model answers, decisions, and later outcomes into one view.

It combines:

- highest-priority prepared task
- exact Evidence-State Receipt
- provider-neutral copy/download handoff
- recorded ChatGPT, Claude, Grok, or other result
- comparison of results that used the same receipt
- review and typed memory proposal
- durable decision, forecast, thesis, or commitment
- later outcome and calibration

## What it shows

The screen answers:

1. What needs judgment now?
2. Is the evidence sufficient?
3. Which exact context will the model see?
4. What did each model conclude?
5. What did I decide?
6. When should that decision be reviewed?

Everything else remains available through Story, Mission, Memory, and System detail views.
