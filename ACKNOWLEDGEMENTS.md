# Acknowledgements

Driftglass builds on open-source work across source collection, Cloudflare applications, and the Model Context Protocol.

## Core integrations

- [Cloudflare Agents SDK](https://github.com/cloudflare/agents) provides MCP transport and Cloudflare application primitives.
- [Cloudflare Computer](https://github.com/cloudflare/computer) provides the optional Computer Power Mode workspace.
- [OpenCLI](https://github.com/jackwener/OpenCLI) is the primary signed-in collection layer for the optional Companion.
- [Agent-Reach](https://github.com/Panniantong/Agent-Reach) is an optional capability router and diagnostics tool.

## Other projects and references

- [Horizon](https://github.com/Thysrael/Horizon) informed parts of the multi-source research and delivery model.
- [twscrape](https://github.com/vladkens/twscrape), [x-tweet-fetcher](https://github.com/ythx-101/x-tweet-fetcher), [XActions](https://github.com/nirholas/XActions), [twitter-cli](https://github.com/public-clis/twitter-cli), and [rdt-cli](https://github.com/public-clis/rdt-cli) provide useful approaches to replaceable social-source collection.
- [yt-dlp](https://github.com/yt-dlp/yt-dlp) provides media metadata and subtitle infrastructure.
- [birdclaw](https://github.com/steipete/birdclaw) demonstrates a local-first social archive and workspace.

Integrated tools remain separately installed under their own licenses. Bundled dependencies retain the licenses recorded in their packages and lockfiles.
