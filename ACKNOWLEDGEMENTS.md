# Acknowledgements

Driftglass composes a Cloudflare-native intelligence layer with open-source projects that solve difficult, fast-moving access problems. The project links those upstreams prominently and keeps their contributions visible.

## Primary integrations

### OpenCLI

[OpenCLI](https://github.com/jackwener/OpenCLI) is the primary signed-in browser execution layer. Its current machine-readable manifest identifies each command as read or write and supplies argument metadata. The Driftglass Companion discovers that manifest, exposes only read adapters, generates source forms from it, and normalizes results into the common evidence schema.

### Agent-Reach

[Agent-Reach](https://github.com/Panniantong/Agent-Reach) is an optional capability-router and diagnostics companion. Its strongest idea is durable routing across changing upstream methods: install, inspect, select, and replace access paths as platforms evolve.

### Horizon

[Horizon](https://github.com/Thysrael/Horizon) is a strong reference for multi-source profiles, deduplication, scoring, comment enrichment, and report delivery. Driftglass credits it as product inspiration and an alternative architecture; no Horizon code is copied.

## Additional upstreams and references

- [twscrape](https://github.com/vladkens/twscrape) — actively maintained X GraphQL client and a useful optional local fallback.
- [x-tweet-fetcher](https://github.com/ythx-101/x-tweet-fetcher) — multi-backend X normalization and fixture-driven fallback ideas.
- [XActions](https://github.com/nirholas/XActions) — extensive X CLI and MCP work.
- [twitter-cli](https://github.com/public-clis/twitter-cli) and [rdt-cli](https://github.com/public-clis/rdt-cli) — narrow CLI access paths used by the wider agent ecosystem.
- [yt-dlp](https://github.com/yt-dlp/yt-dlp) — media metadata and subtitle infrastructure.
- [birdclaw](https://github.com/steipete/birdclaw) — local-first X workspace and archival ideas.
- [Cloudflare Agents SDK](https://github.com/cloudflare/agents) — stateless MCP, browser bindings, and agent application patterns.
- [Cloudflare Computer](https://github.com/cloudflare/computer) — durable virtual workspaces and pluggable execution used by the optional Computer Power Mode.

## Good-neighbor maintenance

Driftglass publishes the upstream version and provider used for each Companion result, maintains content-bearing probes, reports reproducible upstream defects, contributes generally useful fixes upstream, and keeps external license boundaries explicit.
